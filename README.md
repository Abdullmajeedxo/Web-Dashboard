Interactive Excel Data Analyzer

A simple and fast web app built with Streamlit that lets you upload Excel files, analyze data visually, filter through records effortlessly, and export your cleaned datasets. No complex setup or coding required.

What it does?

- Easy Upload:** Upload any Excel file directly through a clean, interactive web interface.
- Instant Analysis:** Automatically processes your data in the background using Pandas to give you a clear overview.
- Interactive Visualizations:** Generates dynamic charts using Plotly to help you spot trends and patterns quickly.
- Dynamic Filtering:** Filter, sort, and slice your data on the fly using custom parameters.
- Export Filtered Data:** Download your newly filtered or cleaned dataset back to a fresh Excel file with a single click.

Built with Python — using Streamlit for the web interface, Pandas for data manipulation, and Plotly for interactive charts.
